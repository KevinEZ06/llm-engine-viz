SIMT 深入浅出（one / two / three-loop）

一圈先看控制流，两圈加入结果依赖，三圈再加入寄存器读取和执行资源的限制。

这里的「圈」是书中用来分析 GPU 发射路径的逐层近似，不是所有 GPU 都采用的固定流水线。每增加一圈，模型就多考虑一类会限制发射的条件。

点切换；三圈 = 当前近似加入三类约束

一个 warp 能否发射，要满足三类条件

①
SIMT 状态给出 PC + 有效线程确定取哪条指令，以及哪些线程参与执行
②
记分牌确认依赖已满足源寄存器没有等待中的写回结果
③
读取和执行资源可用操作数收集器、寄存器 bank 和对应执行单元能够接收请求

满足这些条件后，warp 调度器才可能在当前周期选择它。某个 warp 暂时不能发射时，调度器可以选择其他就绪 warp 来隐藏延迟。

小例子：一个 warp 碰到 if / else（SIMT 栈怎么压、怎么弹）

用 8 个线程演示一个 warp（NVIDIA 的 warp 固定 32 个线程）：线程 0–3 执行 if，4–7 执行 else，在 D 处重新汇合。栈表项 =〈汇合点 PC，下一条 PC，活跃掩码〉。

A: x = load(...)
   if (tid < 4)B:   y = f(x)    // ifC:   y = g(x)    // elseD: store(y)     // 汇合

汇合点 PC下一条 PC活跃掩码
紫色那行 = 当前栈顶（TOS），经典模型按它推进控制流
